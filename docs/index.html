Quickstart: Start Local GPU or Mock Server

Clone this repository and launch the FastAPI server with mock verification (zero GPU needed) or full PyTorch + MONAI + Hugging Face GPU inference:

git clone https://github.com/prazg/Lung_Radiology_FM_Portal.git
cd Lung_Radiology_FM_Portal/backend

# 1. Lightweight mock + NIfTI slice preview server (no GPU required)
pip install -r requirements-server.txt
PORTAL_MOCK=1 uvicorn server:app --host 127.0.0.1 --port 8000

# 2. Full GPU inference (PyTorch + MONAI + Hugging Face + TotalSegmentator)
pip install -r requirements.txt
uvicorn server:app --host 127.0.0.1 --port 8000

# 3. Remote HPC GPU workstation via SSH port forwarding
ssh -N -L 8000:127.0.0.1:8000 user@gpu-cluster.institution.edu
