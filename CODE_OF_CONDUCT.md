# Code of Conduct

This open-science repository follows the Contributor Covenant principles for respectful, inclusive, and constructive collaboration across radiology, thoracic oncology, and medical AI research.

- Critique methods, benchmarks, and code constructively; never individuals.
- Attribute original authors, datasets, licenses, and clinical guidelines accurately.
- Never upload protected health information (PHI), identifiable DICOM headers, or unauthorized gated model weights in issues or pull requests.
